# HadirOne 1.5.3

Versi Android: 1.5.3 (version code 27), distribusi APK langsung.

- Bagikan bukti transaksi PPOB melalui menu berbagi Android ke WhatsApp, Telegram, dan aplikasi lain.
- Cetak struk PPOB melalui layanan cetak Android atau simpan sebagai PDF.
- Cetak struk langsung ke printer thermal Bluetooth Classic yang kompatibel, dengan pilihan kertas 58/80 mm.
- Pilihan printer dan status pengiriman struk tersedia pada halaman transaksi berhasil.

Fitur struk memerlukan pembaruan halaman PPOB pada server HadirOne. Pasangkan printer melalui pengaturan Bluetooth HP sebelum memilih printer di aplikasi.

APK menggunakan identitas aplikasi dan sertifikat penandatangan yang sama dengan versi 1.5.2. Pengujian printer fisik belum dilakukan; kompatibilitas bergantung pada printer dan layanan cetak perangkat.
